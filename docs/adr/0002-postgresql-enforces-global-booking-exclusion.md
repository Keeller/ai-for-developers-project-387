# PostgreSQL гарантирует отсутствие пересечений Бронирований

База данных запрещает любое положительное пересечение интервалов Бронирований
ограничением PostgreSQL независимо от Типа события. Проверки приложения дают
понятные ошибки, но инвариант принадлежит базе, чтобы параллельный или сторонний
клиент не мог создать конфликтующие Бронирования.
