# Один переносимый образ запускает web и API

В production используется один многоэтапный Docker-образ, в котором Fastify
обслуживает API и собранное React-приложение на порту из `PORT`. Railway
запускает тот же образ с управляемой PostgreSQL, а отсутствие специфичных для
Railway инструкций сохраняет переносимость на локальный Docker и другие хосты.
